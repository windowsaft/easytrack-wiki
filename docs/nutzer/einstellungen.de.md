# Einstellungen

Die **Einstellungen** liegen unter **Profil → Einstellungen** und enthalten die
app-weiten Voreinstellungen. Deine Ziele und Körperdaten liegen woanders — unter
[Ziele](ziele.md) — damit dieser Bildschirm darum geht, *wie sich die App verhält*, nicht um
deine Zielwerte.

## Sprache

EasyTrack gibt es auf **Deutsch und Englisch**. Wähle eine feste Sprache oder
**Systemsprache**, um dem Telefon zu folgen. Die Änderung greift sofort, ohne Neustart.

## Einheiten & Anzeige

- **Einheiten** — das Maßsystem (metrisch).
- **Design** — das visuelle Erscheinungsbild der App.

## Aktivität

- **Aktivität erhöht Budget** — ist die Option an (Standard), werden manuell eingetragene
  verbrannte Kalorien deinem Tagesbudget hinzugefügt. Aus geschaltet trägst du Aktivität ein,
  ohne dass sie dein Ziel verändert. Siehe [Tagebuch](tagebuch.md).

## Produktdaten

Lade ein **Open-Food-Facts-Paket**, um die Offline-[Suche](suche-barcode.md) um Marken- und
Barcode-Produkte zu erweitern:

- **Region** — welches Paket geladen wird.
- **Produktdatenbank** — der Button **Herunterladen** / **Aktualisieren** mit Größenangabe und
  Fortschrittsbalken; ein laufender Download lässt sich abbrechen. Das Paket wird geprüft und
  atomar getauscht — ein fehlgeschlagener Download rührt das vorhandene Paket nicht an.
- **Paket aus Datei laden** — ein Paket aus einer lokalen Zip importieren, statt es
  herunterzuladen.

Das Paket ist von der automatischen Android-Cloud-Sicherung ausgenommen (siehe
[Datenschutz](datenschutz.md)).

## Datensicherung

- **Daten sichern** — alles als Zip exportieren, die dir gehört.
- **Daten wiederherstellen** — eine Sicherungs-Zip importieren.

Beides ist unter [Datensicherung](datensicherung.md) ausführlich beschrieben.

## Diagnose

- **Protokoll exportieren** — das App-Protokoll als Datei teilen, hilfreich beim Melden eines
  Problems.
- **Protokoll leeren** — die aktuellen Protokolleinträge verwerfen.

## Aktualisierungen

Bei Sideload-Installationen prüft EasyTrack die Releases-Seite und zeigt oben in den
Einstellungen ein Banner **„Neue Version verfügbar"**, sobald ein neuerer Build vorliegt.
Siehe [Installation](installation.md#aktualisieren).
